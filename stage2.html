기초 공부 2단계

📅 학습 기간: 3-4개월 (9주차 - 16주차)

강화학습의 기초 이론과 고전적인 알고리즘들을 학습하고 구현합니다.

🎯 학습 목표

  • MDP 이해: Markov Decision Process의 개념과 수학적 정의
  • Value Function: State Value Function과 Action Value Function (Q-Function) 이해
  • Bellman Equation: Bellman Expectation/Optimality Equation 유도 및 이해
  • Dynamic Programming: Policy Iteration, Value Iteration 알고리즘 구현
  • Monte Carlo & TD Learning: MC, SARSA, Q-Learning 알고리즘 구현
  • 환경 구축: OpenAI Gym을 활용한 RL 환경 설정 및 실험
