연구 시작 단계

📅 기간: 10–12개월 (37주차–52주차)

원하는 분야에서 흥미로운 문제를 정의하고, 아이디어 구상·구현을 통해 독립적인 연구 프로젝트를 수행합니다. 베이스라인을 정확히 재현하고, 점진적으로 개선안을 제안·검증합니다.

🎯 목표

  • 연구 문제 정의: 명확한 문제 설정과 가설 수립
  • 베이스라인 확보: 관련 대표 논문 1–2편 충실 재현
  • 아이디어 구상: 한계 분석 → 개선 아이디어 도출
  • 방법 개발: 알고리즘/모듈 설계 및 구현
  • 실험/분석: 체계적 실험, 어블레이션, 통계 분석
  • 논문화: 학술 형식의 보고서/논문 초고 작성

🧭 진행 방향

  • 베이스라인 논문 읽기 — 문제정의/가정/핵심 아이디어/한계 체크리스트화
  • 문제 찾기 — 실제 실패 사례, 데이터 편향, 계산/샘플 효율 등에서 Pain Point 발굴
  • 아이디어 설계 — 단일 변경점(minimal change)→조합 개선 순으로 확장
  • 실험 루틴 — 시드 ≥5, 공정 비교, 재현 가능한 코드/로그/설정 공유
  • 리뷰 루프 — 주간 미팅으로 가설 검증·피드백 반영

📋 연구 프로세스

1️⃣ 문제 정의

활동: 문헌 검토, 한계 파악, 연구 질문·가설 수립

산출물: Problem Statement 1p, 초기 로드맵

2️⃣ 베이스라인 재현

활동: 코드 획득·클린업, 메트릭/환경 정합성 확인

산출물: 재현 리포트(성능·설정·이슈)

3️⃣ 방법 설계

활동: 알고리즘/모듈 설계, 복잡도·자원 추산

산출물: Pseudocode, 실험 계획표

4️⃣ 구현

활동: 모델/훈련 루프/로깅/평가 파이프라인 구축

산출물: 재현 가능한 코드베이스

5️⃣ 실험

활동: 메인·어블레이션·하이퍼스윕

산출물: 결과 표/그래프, 로그 아카이브

6️⃣ 분석

활동: 통계 검증, 실패 케이스/한계 분석

산출물: 분석 노트·결론 정리

7️⃣ 논문 작성

활동: Intro/Related/Method/Exp/Discussion 작성

산출물: 논문 초고

8️⃣ 피드백 & 개선

활동: 지도교수/동료 리뷰 반영

산출물: 카메라레디 초안

🛠️ 연구실 노하우

  • 논문 작성 노하우 — (연구실 구성원 팁 추가 예정)
  • 아이디어 발굴 & 실험 요령 — (연구실 구성원 팁 추가 예정)

🧰 도구 & 리소스

  • 실험 추적: Weights & Biases, Neptune
  • 벤치마크: Gym, dm_control, Procgen
  • 논문·참고: Overleaf, Zotero, Mendeley

✅ 검증 및 마일스톤

📋 문제·아이디어

내용: 문제 정의, 가설·아이디어 명세

기준: 구체성/신규성/실현가능성

💻 구현 & 실험

내용: 베이스라인 재현, 개선안 구현·어블레이션

기준: 재현성·통계적 유의성

👥 연구 미팅

내용: 교수님/동료와 정기 리뷰

기준: 피드백 반영 내역·로드맵 업데이트

📝 논문 초고

내용: 학술 형식의 초고 제출

기준: 구성 완비(초록~결론), 그림·표·부록
