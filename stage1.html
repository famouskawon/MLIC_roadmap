기초 공부 1단계

📅 학습 기간: 1-2개월 (1주차 - 8주차)

강화학습을 본격적으로 시작하기 전에 필요한 머신러닝과 딥러닝의 기초를 다집니다.

🎯 학습 목표

  • Python 프로그래밍 숙달: NumPy, Pandas, Matplotlib 등 데이터 과학 라이브러리 활용
  • 머신러닝 기초 이해: 지도학습, 비지도학습, 회귀, 분류 알고리즘 이해
  • 딥러닝 기본 개념: 신경망, 역전파, 최적화 알고리즘 학습
  • PyTorch/TensorFlow 사용: 딥러닝 프레임워크를 활용한 모델 구현
  • 실습 프로젝트 완수: 기본적인 ML/DL 프로젝트 수행

📚 강의 자료

  • 📹 Andrew Ng - Machine Learning (Coursera)
    coursera.org/learn/machine-learning
    머신러닝의 기초를 체계적으로 배울 수 있는 필수 강의
  • 📹 CS231n - Convolutional Neural Networks (Stanford)
    cs231n.stanford.edu
    딥러닝과 CNN에 대한 심도 있는 이해
  • 📖 Deep Learning Book (Ian Goodfellow)
    deeplearningbook.org
    딥러닝의 이론적 기초를 다지는 교과서
  • 📹 PyTorch Tutorials
    pytorch.org/tutorials
    PyTorch 프레임워크 실습 자료
  • 📖 Python for Data Analysis (Wes McKinney)
    데이터 분석을 위한 Python 활용법

✅ 시험 및 성능 기준

📝 이론 시험

내용: 머신러닝 기본 개념, 딥러닝 알고리즘, 최적화 기법

통과 기준: 80점 이상

💻 코딩 테스트

내용: NumPy, PyTorch를 활용한 신경망 구현

통과 기준: 주어진 문제 80% 이상 해결

🎯 실습 프로젝트

내용: MNIST 또는 CIFAR-10 분류 모델 구현

통과 기준: Test Accuracy 95% (MNIST) 또는 75% (CIFAR-10) 이상

📊 발표

내용: 학습한 내용과 프로젝트 결과 발표

통과 기준: 명확한 이해도 및 설명 능력 시연

💡 주간 학습 계획

  • 1-2주차: Python 기초 및 데이터 과학 라이브러리 (NumPy, Pandas, Matplotlib)
  • 3-4주차: 머신러닝 기초 (선형회귀, 로지스틱회귀, SVM, Decision Tree)
  • 5-6주차: 딥러닝 기초 (Perceptron, MLP, 역전파, 최적화 알고리즘)
  • 7주차: CNN 이해 및 PyTorch/TensorFlow 실습
  • 8주차: 프로젝트 수행 및 발표 준비
